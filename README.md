## О проекте

Одностраничная визитка-портфолио с полностью SVG-превью — никаких растровых картинок, вся графика генерируется кодом.

**Что внутри:**

- 🎨 Логотип-затмение (inline SVG с анимацией)
- 🎮 4 карточки проектов с кастомными SVG-превью
- ✉️ Рабочая форма обратной связи (Web3Forms → почта)
- 🎯 Favicon в виде SVG data URI
- 🌈 Неоновый дизайн с градиентами и glow-эффектами
- 📱 Полностью адаптивный интерфейс

### NEON TETRIS
Тетрис с неоновым дизайном и встроенным ИИ. Оценка позиций на несколько шагов вперёд, адаптивная сложность, управление свайпами на телефоне.
`JavaScript` · `Canvas` · `AI` · `Web Audio`

### CaseBattle
Полноценная веб-игра: открытие кейсов, апгрейд скинов, контракты, продажа, рейтинг, история операций. Собственный бэкенд, база данных и 26 кейсов с разными шансами.
`Python` · `Flask` · `SQLite` · `Web Audio` · `Render`

### Telegram-бот с локальной LLM
Бот на собственной нейросети через LM Studio — без внешних API. Понимает текст, распознаёт картинки, помнит контекст.
`Python` · `Telegram API` · `LM Studio` · `Vision`

### ИИ учится играть в CS2
Экспериментальный проект: обучаю нейросеть самостоятельно играть в шутер. YOLO распознаёт врагов, отдельная модель управляет движением.
`Python` · `YOLO` · `OpenCV` · `Reinforcement Learning`
